# Учебный проект по статистике: A/B-тест и анализ данных маркетплейса

Проект выполнен как учебная работа в рамках модуля «Статистика» курса по аналитике данных.

## Описание

В проекте проверяются бизнес-гипотезы на данных маркетплейса: влияние нового дашборда на время обработки заказов, влияние бесплатной доставки на активность клиентов, а также связь между типом товара и стажем продавцов.

## Используемые методы

- описательная статистика;
- t-тест для независимых выборок;
- t-тест для парных выборок;
- критерий хи-квадрат для таблицы сопряжённости;
- доверительные интервалы.

## Основные выводы

- Новый интерактивный дашборд статистически значимо уменьшил среднее время обработки заказов продавцами.
- После введения бесплатной доставки клиенты стали делать статистически значимо больше заказов.
- Статистически значимой связи между типом продаваемых товаров и стажем продавцов не обнаружено.

## Технологии

Python, pandas, scipy, matplotlib, Jupyter Notebook.
